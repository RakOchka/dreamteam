## Описание проекта

DreamTeam — учебный командный репозиторий для освоения Git и GitHub.
Проект предназначен для практики совместной работы с файлами и системой контроля версий.
Участники учатся создавать ветки, коммиты, отправлять изменения и решать конфликты слияния.
Также команда использует GitHub Issues для постановки, выполнения и проверки задач.
Основная цель проекта — освоить инструменты совместной разработки и командного взаимодействия.



\## Правила командной работы



1\. \*\*Создание коммитов.\*\* Каждый коммит должен быть атомарным и осмысленным, сообщение кратко описывает изменение. Один коммит — одна логическая правка.



2\. \*\*Получение обновлений.\*\* Перед началом работы и перед пушем всегда выполняйте `git pull origin main`, чтобы работать с актуальной версией кода.



3\. \*\*Работа с Issues.\*\* Каждая задача оформляется как Issue с понятным описанием, перед выполнением переводится в «In Progress», после завершения — закрывается.



4\. \*\*Проверка изменений.\*\* Перед коммитом просматривайте diff (`git diff`), убеждайтесь, что в изменениях нет лишнего и проект собирается.



5\. \*\*Разрешение конфликтов.\*\* При конфликте слияния откройте файл, удалите маркеры `<<<<<<<`, `=======`, `>>>>>>>`, оставьте корректный вариант, затем выполните `git add`, `git commit` и `git push`.
