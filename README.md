## Описание проекта

DreamTeam — учебный командный репозиторий для освоения Git и GitHub.
Проект предназначен для практики совместной работы с файлами и системой контроля версий.
Участники учатся создавать ветки, коммиты, отправлять изменения и решать конфликты слияния.
Также команда использует GitHub Issues для постановки, выполнения и проверки задач.
Основная цель проекта — освоить инструменты совместной разработки и командного взаимодействия.
